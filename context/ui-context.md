# ZenZebra CRM — UI Context

The Apple-glassmorphism style requested for the Customer Retention module
**is already implemented** on the existing retention pages
(`src/app/(main)/dashboard/retention/overview/page.tsx`,
`.../cohorts/page.tsx`, and siblings) and matches the visual language of the
Sales dashboard. Match these exactly for any new page — don't introduce a
new visual system.

## Design tokens

Tailwind v4, CSS-based config via `@theme inline` in `src/app/globals.css`,
colors in OKLCH. Four switchable presets (default/grayscale, Soft Pop,
Brutalist, Tangerine) live in `src/styles/presets/*.css`, generated by
`npm run generate:presets` (also run automatically pre-commit — see
`code-standards.md`). Don't hand-edit generated preset files.

Token families (all presets, light + `.dark`):
- `--background`, `--foreground`, `--card`, `--card-foreground`
- `--primary`, `--secondary`, `--muted`, `--accent` (+ `-foreground` pairs)
- `--destructive`, `--border`, `--input`, `--ring`
- `--chart-1` … `--chart-5` — the recharts data-viz palette
- `--sidebar-*` — nav-specific colors

Radius scale derives from a single `--radius` base (default `0.625rem`):
`--radius-sm/md/lg/xl/2xl/3xl/4xl` via `calc(var(--radius) ± Npx)`.

Dark mode: `.dark` class on `<html>`, driven by `data-theme-mode`
(`light|dark|system`), persisted via `PreferencesStoreProvider`
(`stores/preferences/preferences-store.ts`) with a pre-hydration boot script
to avoid flash.

## Card convention (the "glass card")

This exact className pattern is the standard card treatment used across
retention and sales pages — reuse it verbatim, don't invent variations:

```
rounded-2xl border border-white/10 bg-white/5 dark:bg-black/20
backdrop-blur-xl shadow-[0_8px_32px_rgba(0,0,0,0.08)]
```

Applies to KPI cards, trend/chart cards, and the AI Insights panel.

## KPI cards

Use the existing `MetricCard` component
(`src/components/ui/metric-card.tsx`) — title, large value, growth-arrow
badge, icon top-right. Grid: `grid gap-4 grid-cols-2 lg:grid-cols-3`.

## Charts

`recharts`, wrapped via `src/components/ui/chart.tsx`
(`ChartContainer`/`ChartTooltip`). Area charts use gradient fills keyed to
`--chart-*` tokens or direct hex (`#3b82f6` blue, `#10b981` green seen in
existing trend charts). Standard margin: `{ top: 10, right: 10, left: -20,
bottom: 0 }`.

## Tables / heatmaps

Data cells: `font-mono text-[11px]`. Cohort/metric-family color coding
(used on the Cohorts page and reusable for any new heatmap-style table):
- Retention: blue (`bg-blue-500/20 text-blue-600 dark:text-blue-400`)
- Revenue: emerald
- AOV: indigo
- Bill cuts: amber

Cell intensity scales with value via inline `rgba(..., opacity * 0.45)`,
not a fixed shade — see `cohorts/page.tsx` for the exact pattern before
building a new heatmap.

## AI Insights panel

Card with the glass treatment, `Sparkles` icon (amber-500) in the title,
bullet list, and a highlighted recommendation box:
`rounded-xl bg-amber-500/10 border border-amber-500/20 p-3`. This is the
pattern for any "what happened / why / what to do" interpretation block —
reuse it rather than designing a new callout style.

## Typography

Default font is Geist (`--font-geist`), switchable among ~16 Google Fonts
via `src/lib/fonts/registry.ts` and a `data-font` attribute on `<html>`.
Conventions actually in use:
- Page h1: `text-3xl font-bold leading-none tracking-tight`
- Section h2: `text-2xl font-bold`
- Card title: `text-base font-medium` (via shadcn `CardTitle`)
- Body: `text-sm`; muted: `text-sm text-muted-foreground`
- Data/mono: `font-mono text-[11px]`

## Shadcn config

`components.json`: style `radix-nova`, base color `neutral`, CSS variables
on, icon library `lucide`. Aliases: `@/components`, `@/components/ui`,
`@/lib`, `@/hooks`. Component inventory lives in `src/components/ui/`
(40+ primitives — Card, Tabs, Table, Badge, Select, Dialog, Drawer, Sheet,
Skeleton, Tooltip, Popover, DateRangePicker, etc.) plus domain components in
`components/founder/`, `components/store-overview/`, `components/dashboard/`.

## Loading states

Skeleton placeholders matching the target shape, e.g.
`className="h-[120px] rounded-2xl"` for a KPI card,
`h-[400px]` for a chart card. Always glass-card shaped, not a generic gray
box.

## Spacing

Page wrapper: `p-4 md:p-8 pt-4`. Section gap: `gap-6`. In-card content gap:
`gap-4`. Don't invent a different grid unit for new retention pages.
